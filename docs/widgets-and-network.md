# 桌面小组件与 Codex 代理

基于 1.2.35（5777ae1）的代码审查：原有自动刷新运行在 ViewModel 中，应用进程结束后不会继续；没有 AppWidgetProvider。Codex 使用 access token、account ID 请求 `chatgpt.com/backend-api/wham/usage`，失败再尝试另一条同域接口，切换路径不能解决网络出口问题。

## 小组件

- 提供 2×2 和 4×2 两个独立入口，关闭拖动调整。占用格数由 Launcher 实现，实际像素随设备、桌面网格及字体设置变化。
- 每个实例绑定一个已有账户，新增与编辑时选择来源。删除账户后显示“请选择 AI 源”，不会自动切换到其他账户。
- 系统恢复会为小组件分配新 ID；按尺寸入口隔离并迁移绑定，避免两个入口的旧、新 ID 交叉时串号。Android 12+ 换机迁移同时保留账户与组件绑定；云备份不含账户凭据，需手动导入账户备份。
- 余额类（如 DeepSeek）仅展示余额主值，不展示赠送/充值等无关附加字段；所有来源有可计算的用量窗口时优先展示额度，余额字段不遮挡窗口。
- 额度类展示剩余百分比、进度条和绝对重置时间，只使用已返回的窗口。2×2 最多展示两个窗口；4×2 最多三个（火山 5 小时、周、月）。使用淡色圆角卡片，周期名称与数值分层显示；可用高度不足 140dp 时使用并排紧凑布局，周期名与百分比分行、重置日期和时分分行，避免数字换行后被隐藏。较窄的 4×2 三列布局也将重置日期与时分分行，防止时间被截断。
- 4×2 仅在归一化数据的 extras 确有 `reset_cards`、`reset_card_count` 或“重置卡”等非负整数数量时显示数量角标；没有确认的官方接口字段，不推测或显示虚构的 0。极小尺寸省略角标。
- 显示最近一次成功取数时间；失败保留旧值并标记过期，避免误认为刚查询成功。
- 保留原有小字刷新状态提示。网络失败不清空余额、窗口百分比或重置时间，App 内继续显示错误详情。
- 两种尺寸的成功更新提示使用精简时间：今天显示时分，较早数据显示月日；4×2 的刷新失败提示保留上次成功的完整时间。
- 横排额度卡片预留统一的周期名称和重置时间高度，确保数字与进度条对齐。未返回重置时间时显示“重置 —”（紧凑版仅显示 —），不推算时间，也不挤掉其他列的时间区域。
- 应用保存结果后同步更新所有绑定的小组件；小组件刷新后首页同步读取最新存储。
- 点击刷新立即提交后台任务。同一来源的刷新去重；定时任务只查询小组件实际绑定的来源。
- 后台任务使用 WorkManager，跟随已有自动刷新设置，最短 15 分钟；设置 0 时禁用定时查询。Doze、断网、强制停止及 HyperOS 省电限制可能延迟执行，不承诺持续实时。
- Android 12+ 使用系统小组件圆角参数和背景标识；较旧系统使用 24dp 圆角。HyperOS 4 的桌面格数、裁切及省电行为需要真机验收。
- 按用户提供的小米桌面截图，将可见卡片顶部内缩 12dp，底边保持不变，格子占位仍为 2×2/4×2；DeepSeek 图标修正为等比绘制。

## Codex 网络

- Codex 的官方 API 模式增加账户级代理 URL，可留空沿用当前系统网络。
- 支持 `http://主机:端口`（HTTPS CONNECT）或 `socks5://主机:端口`；不支持 URL 内用户名密码，不设置全局 JVM 代理，不影响其他账户。
- 主查询和同域备用查询共用该代理；配置有误时直接报告错误，不偷偷回退直连。
- HTTPS 仍验证官方服务器证书。不能为了公用节点或镜像关闭 TLS 验证。
- 127.0.0.1 指手机本身；电脑代理要使用手机可访问的电脑局域网地址，并配置代理软件允许局域网访问。应用无需修改防火墙或获得 VPN 权限。
- 这是代理连接功能，不含免费出口节点。公用镜像可能接触 access token；默认不接入未知服务。
- 另一条现有路径是 WEBHOOK：在自己控制的服务端保存凭证并查询官方接口，手机仅携带中转服务自己的访问密钥。服务端可返回归一化额度 JSON 或原厂响应，凭证无需传给第三方镜像。
- 代理地址随账户一起本地保存、导入导出；旧备份缺少字段时仍正常读取。

## 验收

新增、取消及重新编辑两种尺寸；两个组件选择不同账号且刷新互不串号；同账号多实例同步；账户删除/导入/编辑与后台请求交错时不复活或覆盖新配置；断网保留旧数据并标记；应用前后台刷新同步；主题及字体；重启后的定时任务。自动检查包含现有回归套件、代理真实本地 HTTP/SOCKS5 请求、小组件 Manifest 与 RemoteViews、后台事务测试、lint 和 APK 构建。
